# Connecting to MongoDB in Node.js

Neste novo módulo, sairemos do ambiente interativo do terminal (`mongosh`) e passaremos a utilizar a linguagem de programação **JavaScript/Node.js** para nos conectarmos de maneira programática a um cluster do MongoDB Atlas.

Aprenderemos como instalar o driver oficial do MongoDB para Node.js, como inicializar a conexão usando a Connection String, configurar os clientes (`MongoClient`) e fazer as devidas requisições assíncronas ao banco de dados, preparando o terreno para construir aplicações backend reais (APIs, microsserviços, etc).

## 🎓 Conclusão: Connecting to MongoDB in Node.js

Nesta unidade sobre a integração com Node.js, você aprendeu a:

* **Install** the Node.js MongoDB driver with Yarn (ou npm).
* **Connect** to your Atlas cluster from a Node.js application.
* **Use** the `MongoClient` instance.
* **Troubleshoot** common connection issues when using the MongoDB driver.
